## Descripción

Sistema desarrollado en lenguaje C para gestionar el funcionamiento básico del Terminal Portuario Turístico de Buenaventura.

El proyecto implementa:

- Destinos turísticos dinámicos.
- Colas FIFO para pasajeros.
- Árbol Rojo-Negro para viajes programados.
- Búsqueda de pasajeros y viajes.
- Embarque de pasajeros.
- Estadísticas básicas.

## Compilación

```bash
gcc parcial3.c -o terminal
```

## Ejecución

```bash
terminal
```

## Estructuras utilizadas

- FIFO (First In First Out)
- Árbol Binario de Búsqueda
- Árbol Rojo-Negro
